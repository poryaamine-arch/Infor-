# INFERNO Android project

این پروژه نسخه WebView لانچر INFERNO است و برای ساخت APK در Android Studio آماده شده است.

## ساخت APK
1. Android Studio را نصب کنید.
2. از مسیر File > Open پوشه `INFERNO_Android_Project` را انتخاب کنید.
3. اجازه دهید Gradle Sync تمام شود (این مرحله به اینترنت نیاز دارد تا افزونه‌ها و Android SDK دریافت شوند).
4. از منوی Build > Build Bundle(s) / APK(s) > Build APK(s) را بزنید.
5. فایل APK در مسیر `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## نکته
این محیط Android SDK و Gradle نصب‌شده ندارد؛ بنابراین در اینجا امکان کامپایل و تحویل APK واقعی وجود ندارد. این ZIP سورس کامل پروژه اندروید است که در Android Studio قابل ساخت است.
